# 공개 범위와 권리 검토

검토일: 2026-10-06. 대한민국 법령과 GitHub 정책을 참고한 프로젝트 준비 기록이며, 개별 사안의 적법성을 확정하는 법률 의견은 아닙니다. 현재 Gun Nac 권리자의 이용허락을 확인한 자료는 없습니다.

## 판단

**ROM과 폰트를 빼도 완성 한국어 번역문과 패치가 자동으로 자유 배포 가능한 것은 아닙니다.** 저작권법 제5조는 번역에 의한 2차적저작물과 원저작자의 권리를 구분하고, 제22조는 원저작물을 바탕으로 작성·이용하는 권리를 규정합니다. 한국저작권보호원의 게임 안내서는 유저 한글패치도 원칙적으로 동의가 필요하다고 설명합니다.

- [저작권법 제5조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0005&lsiSeq=283335&urlMode=lsScJoRltInfoR)
- [저작권법 제22조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0022&lsiSeq=283335&urlMode=lsScJoRltInfoR)
- [한국저작권보호원 게임 저작권 안내서](https://kcopa.or.kr/download.do?uuid=ee910f63-9bf3-4cdf-a94d-0ce228de724e.pdf), 본문 15쪽/PDF 15쪽의 유저 한글패치 설명.

공정한 이용은 이용 목적·성격, 저작물의 종류, 사용 비중과 중요성, 시장 영향을 종합해 판단합니다. 무료·비영리·팬 번역·출처 표시 중 하나만으로 충족되는 것으로 가정하지 않습니다. 오래된 게임이거나 현재 판매처를 찾기 어렵다는 사정도 권리 소멸의 확인을 대신하지 않습니다. [제35조의5](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=05&joNo=0035&lsiSeq=283335&urlMode=lsScJoRltInfoR)

프로그램코드역분석 예외도 정당한 이용 권한, 호환 목적과 필요한 범위 등의 조건이 있습니다. 한글화 연구 전체에 무조건 적용된다고 판단하지 않았습니다. 본 도구가 로컬 ROM을 받는다는 사실만으로 그 ROM의 취득·복제·분석·변형이 모두 허용됨을 증명하지는 않습니다. [제101조의4](https://law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=1017054983)

## 파일별 취급

| 자료 | 이번 취급 | 남는 검토 사항 |
| --- | --- | --- |
| 일본·영어·한국어 ROM | 제외 | 구매·보유와 공개 복제/배포 허락은 별개 |
| 게임 CHR·음원·로고·화면 캡처·전체 역어셈블 덤프 | 제외 | 필요한 인용의 범위도 개별 검토 |
| 일본어 대사 전문·원본 바이트 | 제외 | 사용자의 로컬 ROM에서만 추출 |
| 완성 한국어 대사·줄바꿈 자료 | 소스 저장소에 포함 | 원작의 번역·이용 권리 확인 |
| 완성 IPS | ZIP으로 Releases에 배포 | IPS에도 복사된 원본 PRG/CHR와 폰트 패턴이 들어갈 수 있음 |
| 한글 폰트 파일 | 제외 | 공식 출처·고정 버전·라이선스 안내만 제공 |
| 자체 작성 도구·기술 문서·번역 작업표·주소·해시 | 소스 저장소에 포함 | 복제된 표현·역분석 조건·공개 라이선스 범위의 최종 확인 |

소스와 생성물의 분리는 적법성 보증이 아닙니다. 숫자 주소나 해시 정보와 원작의 표현을 복제한 자료를 구분하고, 기능 구현 코드에 필요한 짧은 바이트 검사와 전체 게임 코드 덤프를 혼동하지 않습니다.

## 라이선스 적용 범위

자체 작성한 도구 코드(`tools/`), 저장소 자동화(`.githooks/`, `.github/`)와 기술 문서(`README.md`, `CONTRIBUTING.md`, `docs/`)에는 [MIT 라이선스](../LICENSE)를 적용합니다. 저작권 표시와 허가문을 유지하면 수정·재배포·상업적 이용이 가능합니다.

이 허락은 프로젝트 기여자가 권리를 보유한 부분에 한합니다. 원작 게임의 코드·데이터·그래픽·대사, 한국어 번역문과 배치 자료(`translation/`), 패치에 포함된 원작 유래 자료에는 적용하지 않습니다. 코드 안의 원작 유래 바이트·표현에도 새로운 권리를 부여하지 않습니다. 외부 폰트는 각 공식 배포 라이선스를 따릅니다. 저장소 전체나 배포 IPS 전체를 MIT로 허가한다는 의미가 아닙니다.

## GitHub와 비공개 저장소

GitHub에 업로드할 수 있다는 기술적 사실과 적법성 판단은 다릅니다. GitHub는 유효한 저작권 신고에 따라 콘텐츠 접근을 차단할 수 있습니다. 비공개 저장소도 제3자 제공·복제 등에 대한 권리 확인을 대신하지 않습니다. ‘private로 먼저 올리면 합법’이라는 안내를 하지 않습니다. [GitHub DMCA 정책](https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy)

소스의 `.gitignore`, 게시 파일 목록, staged 검사, CI는 실수로 에셋을 포함하는 일을 줄이는 도구입니다. 법적 적법성을 자동 판정하거나 이미 공개된 Git 이력에서 파일을 지우는 도구는 아닙니다.

## 권리 확인

실제 현재 권리자와 팬 번역 정책을 확인하고, 한국어 번역·게임 변경·번역 소스/패치 공개·제3자의 수정·재배포를 허용하는 범위를 문서로 확인하는 편이 가장 명확합니다. 기존 개발사 이름만 보고 현재 권리자를 단정하지 않습니다. 구체적 이용 계획과 산출물 목록을 가지고 한국저작권위원회 또는 저작권 분야 변호사에게 검토받을 수 있습니다. 권리자가 불명이라는 사정만으로 허락을 추정하지 않습니다. [한국저작권위원회](https://www.copyright.or.kr/)
